# 人物分类体系 / Figure Categories

本文档用于AI猜人物模式的二分法决策树，帮助AI高效缩小候选范围。

## 一级分类：时代 / Era (L1)

| 分类 | 时间范围 | 英文 |
|------|---------|------|
| 上古/古代 | 公元前 | Ancient / Before Common Era |
| 中古 | 公元1年-1500年 | Medieval / 1-1500 CE |
| 近代早期 | 1500年-1800年 | Early Modern |
| 近代/现代 | 1800年至今 | Modern |

**决策问题**：
> "此人活跃于公元1年之前吗？/ Was this person active before 1 CE?"

| 分类 | 中文 | 定义 | 英文 |
|------|------|------|------|
| 家喻户晓 | 教科书级 | 全球或主要文化圈内几乎人人知晓 | Household name / Iconic |

## 二分法提问策略

### Phase 1: 粗筛 (1-4问)

目标：确定时代、地域、领域

**提问原则**：不要每次都用同样的问题。从多个备选问法中随机选择，保持新鲜感。

**标准维度与备选问法**：

| 维度 | 默认问题 | 备选问法 |
|------|---------|---------|
| 时代 | "公元1年之前？" / "Before 1 CE?" | "此人对电灯泡会惊讶吗？" / "见过印刷术吗？" / "活在一千多年前吗？" |
| 地域 | "东亚？" / "East Asia?" | "赤道以北？" / "地中海沿岸？" / "以茶文化闻名的地区？" / "古代文明发源地？" |
| 领域 | "亲自上过战场拿武器吗？" / "Personally fought with weapons?" | "统治过国家吗？" / "写过流传至今的作品吗？" / "做过实验/观测吗？" / "创立过思想流派吗？" |
| 性别 | "男性？" / "Male?" | "女性？" / "Female?" |

**开场顺序**：不要固定为 时代→地域→领域→性别，每局随机打乱顺序。

### Phase 2: 精筛 (5-12问)

目标：缩小到具体子类

**核心原则**：用行为/经历式提问，不用抽象标签。

**根据领域细分**：
- 政治/军事："继承权力还是自己打下来的？""以个人武力闻名还是以谋略闻名？"
- 科学："关于理解自然世界的吗？""发明/发现了至今仍在用的东西吗？""主要靠数学工具工作吗？"
- 文学："主要是诗歌还是散文/小说？""在世时就因作品而知名吗？"
- 艺术："绘画？音乐？雕塑？""作品是否被博物馆收藏？"
- 哲学/宗教："创立了新思想流派还是追随前人？""因思想遭受过迫害吗？"

### Phase 3: 定位 (13-20问)

目标：精确识别具体人物

**策略**：
- 根据已确认属性，列举候选
- 用具体的经历/行为排除，不问"是什么人"
- 最后几个问题直接针对最可能的候选

**示例问题**：
> "此人是否在战争中以少胜多？/ Won against the odds?"
> "此人的某个行为是否成了成语/典故？/ Did an action become an idiom?"
> "此人是否与某著名建筑/地标有关？/ Associated with a famous landmark?"
