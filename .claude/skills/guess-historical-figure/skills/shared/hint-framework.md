# 线索等级体系 / Hint Framework

本文档定义AI出题模式中线索的8级等级体系。

## 核心原则

### 1. 每条线索提供新维度信息
后续线索不得与前面已揭示的线索形成信息叠加。例如：
- ❌ L1说"11世纪" → L2说"东亚"（两条组合后范围缩太小）
- ✅ L1说"公元前某个时期" → L2说"此人的影响力跨越了地域限制"（不同维度）

### 2. 随机维度组合
每条线索从以下维度池中随机挑选，不要按固定顺序：

| 维度 | 说明 | 粗粒度示例 | 细粒度示例 |
|------|------|-----------|-----------|
| 时代 | 时间范围 | "公元前某个时期" | "公元8世纪" |
| 地域 | 地理范围 | "影响波及多个文化圈" | "来自地中海沿岸" |
| 领域 | 职业/身份大类 | "与文字/语言有关" | "政治军事人物" |
| 成就类型 | 做了什么类型的事 | "与大规模建设有关" | "完成了一次统一" |
| 个人经历 | 人生中特殊的事件 | "曾经历过流亡" | "在30岁前就已成名" |
| 同时代关联 | 与其他人物/事件的关系 | "同时代有比此人更出名的人" | "与某著名建筑有关" |
| 文化符号 | 隐含文化线索 | "此人所在地区有一种世界闻名的饮品" | "与此人相关的节日至今仍在庆祝" |
| 性别 | 男/女 | — | "此人是女性" |
| 知名度 | 知名程度 | "此人的名字常出现在日常用语中" | "教科书级人物" |
| 结局/命运 | 人物结局 | "此人结局并不圆满" | "死于非命" |
| 名言/典故 | 与此人相关的言语或典故 | "此人的某个行为成了成语" | "此人说过：XXX" |
| 姓名 | 名字的特征 | — | "姓X" / "名以X开头" |

### 3. 信息量递进控制

**L1-L3（前期）**：
- 每条线索只从单一维度切入
- 每条最多排除全球历史人物的30%
- 禁止两个维度叠加（如"11世纪的中国人"）
- 尽量用间接、模糊的表述

**L4-L6（中期）**：
- 可以组合1-2个维度
- 中等粒度，但仍不直接点名
- 可以给出更具体的成就类型

**L7（后期）**：
- 名言引用或具体典故
- 足以让人锁定答案但仍有悬念

**L8（最终）**：
- 姓名的一部分（姓、名首字、英文名首字母等）

## 线索数量与难度对应

| 难度 | 最大线索数 |
|------|-----------|
| ⭐ 简单 | 6条 |
| ⭐⭐ 中等 | 8条 |
| ⭐⭐⭐ 困难 | 8条（人物更冷门）|

## 线索生成原则

1. **递进性**：每条比前一条更具体
2. **不重叠**：每条提供前文未提及的新维度
3. **随机性**：每次游戏线索维度排列不同
4. **控制范围**：前几条不能将范围缩得太小
5. **正史为准**：以历史记载为依据
