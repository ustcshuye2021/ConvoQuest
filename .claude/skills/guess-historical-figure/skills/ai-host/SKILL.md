# AI出题模式 / AI Hosts Mode

AI选择一个历史人物，玩家通过提问、盲猜和线索猜测。

---

## 执行流程

### Phase 1: 人物选择

根据用户选择的难度，AI从知识库中选取一个历史人物。

**人物选择规则**：

| 难度 | 人物特征 | 盲猜次数 | 常规猜测上限 |
|------|---------|---------|------------|
| ⭐ 简单 | 家喻户晓（秦始皇、牛顿、李白等） | 1次 | 6次 |
| ⭐⭐ 中等 | 有一定知名度（张衡、南丁格尔、哥白尼等） | 3次 | 8次 |
| ⭐⭐⭐ 困难 | 较冷门（王贞仪、伊本·海赛姆、祖冲之等） | 5次 | 10次 |

### Phase 2: 游戏循环

#### 核心规则

**四选一回答机制**：
玩家向AI提问时，AI只能回答以下四个选项之一：
- **是**：问题的答案明确为真
- **否**：问题的答案明确为假
- **是也不是**：部分正确部分不正确
- **正史无记载**：正史中没有明确记载

无法用四选项回答 → AI要求重新提问（不计入次数）。

**玩家操作**：
1. 提问 → AI四选一回答（扣0.5分）
2. 🎲 盲猜 → 猜错不扣分，消耗盲猜次数
3. 盲猜用完后直接输入猜测 → 猜错扣2分
4. 请求揭示线索

#### 盲猜机制

- 每局有若干次盲猜机会（按难度：简单1次/中等3次/困难5次）
- 盲猜猜错：**不扣分**，只消耗盲猜次数
- 盲猜猜对：正常结算得分
- 盲猜机会用完后：只能通过提问缩小范围，或在输入框直接猜测（猜错扣2分）
- 界面上有专门的🎲盲猜按钮，点击后弹出输入框

#### 计分系统

基础分 **100分**：

| 操作 | 扣分 |
|------|------|
| 提问 | 0.5分/次 |
| 翻开第N条线索 | N分 |
| 盲猜（猜错） | 不扣分 |
| 常规猜测（盲猜用完后，猜错） | 2分/次 |

#### 界面布局

左右两栏：
- **左侧面板**：得分 + 盲猜剩余 + 提问次数 + 线索 + 人物画像
- **右侧对话区**：规则提示 + 对话 + 输入区（含🎲盲猜按钮）

#### 线索设计原则

**核心：后续线索必须提供新维度信息，不能与前面重叠**

每条线索从以下维度中选一个，随机排列：
- 时代、地域、领域、成就类型、个人经历、同时代关联、文化符号、性别、知名度、结局/命运、外貌特征、名言/典故、姓名特征

**信息量控制**：
- L1-L3：每个维度只给最粗粒度，每条最多排除全球人物的30%
- L4-L6：中等粒度，可组合1-2个维度
- L7-L8：最具体，L8涉及姓名

**示例（以秦始皇为例）**：
1. "此人活跃于公元前的某个时期"（时代，粗）
2. "此人的影响超出所在地域，波及整个文化圈"（影响力，不说地域）
3. "此人与大规模建设/工程有关"（事迹类型）
4. "此人建立了一套影响深远的制度"（成就类型）
5. "此人所在地区有一种流行饮品与此人时代有关"（文化符号→茶→中国）
6. "此人统一了多个分散的政权"（具体成就）
7. "此人名字中有一个字意为'开始'"（姓名特征）
8. "此人姓嬴"（姓名）

### Phase 3: 结算

显示人物揭晓、得分、称号、详细扣分明细。

## 特殊情况处理

| 情况 | 处理方式 |
|------|---------|
| 开放式问题 | "请重新提问"，不计入次数 |
| 重复猜测同一人物 | 提醒，不额外扣分 |
| 用户问名字 | 回答"否" |
| 盲猜用完后输入名字 | 当作常规猜测，扣分 |
| 用户放弃 | 揭晓答案，显示得分和称号 |
