# AI猜人物模式 / AI Guesses Mode

用户心中想好一个历史人物，AI通过提问来猜出此人。

---

## 执行流程

### Phase 1: 准备

1. 确认用户已想好人物（不要求用户说出）
2. 内部初始化推理状态：

```
📊 推理面板 / Reasoning Panel
├─ 已确认 / Confirmed: （空）
├─ 已排除 / Ruled out: （空）
├─ 信心指数 / Confidence: ░░░░░░░░░░ 0%
├─ 已提问 / Questions: 0/20
└─ 剩余猜测 / Guesses left: 3
```

### Phase 2: 提问循环

AI按照三阶段策略提问。每次提问前展示推理面板。

#### Stage 1: 粗筛 / Broad Screening (问题1-4)

目标：确定时代、地域、领域、性别

**提问原则**：不要每次都用相同的问题，从备选池中随机挑选，保持新鲜感。

##### 维度1: 时代 / Era

| 备选问题 | 适用场景 |
|---------|---------|
| "此人是公元1年之前活跃的人物吗？/ Was this person active before 1 CE?" | 通用 |
| "如果穿越到现代，此人会对电灯泡感到惊讶吗？（即：是否远早于工业革命）/ Would electricity surprise this person?" | 轻松口吻 |
| "此人生活在一千多年以前吗？/ Did this person live more than a thousand years ago?" | 通用变体 |
| "此人的时代有没有纸张/印刷术/火药？/ Did paper/printing/gunpowder exist in their time?" | 以发明锚定时代 |
| "此人是否活到了看到新大陆被发现？/ Did this person live to see the discovery of the New World?" | 以大事件锚定 |

##### 维度2: 地域 / Region

| 备选问题 | 适用场景 |
|---------|---------|
| "此人来自东亚吗？/ Is this person from East Asia?" | 通用 |
| "此人一生主要生活在赤道以北吗？/ Did this person mainly live north of the equator?" | 南北二分 |
| "此人是否生活在地中海沿岸或附近？/ Did this person live near the Mediterranean?" | 地中海锚定 |
| "此人是否来自一个以茶文化闻名的地区？/ From a region famous for tea culture?" | 文化锚定 |
| "此人是否来自一个古代文明发源地（如两河流域、尼罗河流域、黄河流域等）？/ From an ancient civilization cradle?" | 文明锚定 |

##### 维度3: 领域 / Domain — 用行为而非标签提问

**核心原则**：不要问抽象分类（如"政治人物？""军事人物？""文臣还是武将？"），而是问具体的经历和行为。很多人身兼多职，分类式问题容易模糊。

| 推荐问题 | 替代的旧问法 | 为什么更好 |
|---------|------------|-----------|
| "此人亲自上过战场、拿过武器作战吗？/ Did this person personally fight with weapons on a battlefield?" | ~~"此人是军事人物吗？"~~ | 区分了亲自上阵 vs 运筹帷幄 vs 从未上战场 |
| "此人是否以指挥军队、制定战略而闻名？/ Known for commanding armies and strategy?" | ~~"此人是将军吗？"~~ | 包括了诸葛亮式的战略家 |
| "此人是否写过流传至今的文字作品（书、文章、诗歌等）？/ Did this person write works that survive to this day?" | ~~"此人是文学家吗？"~~ | 涵盖了帝王/政治家也有著作的情况 |
| "此人是否亲手做过实验、观测或计算？/ Did this person do experiments, observations, or calculations?" | ~~"此人是科学家吗？"~~ | 区分了实践型学者 vs 纯理论家 |
| "此人是否曾统治或治理过一个国家/政权？/ Did this person rule or govern a state?" | ~~"此人是政治人物吗？"~~ | 明确区分统治者 vs 政治参与者 |
| "此人是否通过艺术创作（绘画、音乐、雕塑等）闻名？/ Famous for creating art?" | ~~"此人是艺术家吗？"~~ | 更具体 |
| "此人是否创立或深刻影响了某种宗教或哲学思想？/ Founded or deeply influenced a religion or philosophy?" | ~~"此人是宗教/哲学人物吗？"~~ | 包括了非专业哲学家但有哲学贡献的人 |

##### 维度4: 性别 / Gender

| 备选问题 | 适用场景 |
|---------|---------|
| "此人是男性吗？/ Is this person male?" | 通用 |
| "此人是否是一位女性历史人物？/ Is this person a woman?" | 变体 |

##### Stage 1 提问组合策略

**不要每局都用同一套问题**。根据以下策略变化：

- **随机开场**：不总是从"时代"开始，可以任意打乱四个维度的顺序
- **场景代入**：偶尔用情境化的问题（如"此人见过金字塔吗？"代替"此人是非洲/中东人吗？"）
- **文化锚定**：用食物、建筑、发明等文化符号代替直接的地理/时代问题
- **混合使用**：一个维度有多种备选问法，每局随机选一种

**示例——同一局中可能的4种开场**：

> 🎲 开场A（经典顺序）:
> Q1: "公元1年之前活跃？" → Q2: "来自东亚？" → Q3: "亲自上过战场？" → Q4: "男性？"
>
> 🎲 开场B（行为优先）:
> Q1: "此人写过流传至今的作品吗？" → Q2: "此人统治过国家吗？" → Q3: "此人见过电灯泡吗？" → Q4: "女性？"
>
> 🎲 开场C（文化锚定）:
> Q1: "此人时代有印刷术了吗？" → Q2: "此人来自以茶文化闻名的地区？" → Q3: "此人亲手做过实验/观测吗？" → Q4: "男性？"

**提问格式**：

```
❓ Q{N}/20: {问题}

回答方式：是(Y) / 否(N) / 不确定(?) / 不相关(X)
```

**回答记录规则（必须严格遵守）**：

| 用户回答 | 如何记录到推理面板 |
|---------|------------------|
| "是" / "Y" / "yes" | 将问题的命题记入「已确认」<br>例：问"是君主吗？"→答"是"→记"君主/Monarch" |
| "否" / "N" / "no" | 将问题的命题记入「已排除」，或记录其反面到「已确认」<br>例：问"是君主吗？"→答"否"→记"非君主/Not a monarch"到已确认，或记"君主"到已排除 |
| "不确定" / "?" | 不记录，跳过该维度，改从其他角度提问 |
| "不相关" / "X" | 不记录，换一个提问角度 |

**⚠️ 重要：千万不要把"是"和"否"记录反了！**
- 用户说"是" = 确认问题的命题成立
- 用户说"否" = 确认问题的命题不成立（即反面成立）

#### Stage 2: 精筛 / Fine Screening (问题5-12)

目标：缩小到具体子类，排除大量候选

**核心策略**：继续用行为/经历式提问，避免用抽象标签。根据已确认的维度，选择最能二分剩余候选的问题。

**重要**：以下问题仅为参考模板，实际游戏中应根据已收集信息灵活组合、自由发挥，不要照本宣科。每局游戏的问题组合都应该不同。

##### 政治/统治者方向

| 推荐问题 | 避免的旧问法 |
|---------|------------|
| "此人是通过继承获得权力的，还是自己打下来的？/ Inherited power or seized it?" | ~~"此人是帝王还是革命家？"~~ |
| "此人是否在位期间发动过大规模战争或扩张？/ Launched major wars or expansion during rule?" | ~~"此人是扩张型君主吗？"~~ |
| "此人是否死于非命（被刺杀、被推翻等）？/ Did this person die a violent death?" | ~~"此人的结局如何？"~~ |
| "此人是否建立了新的朝代或政权？/ Founded a new dynasty or regime?" | 通用 |

##### 军事方向

| 推荐问题 | 避免的旧问法 |
|---------|------------|
| "此人是以个人武力闻名（如猛将），还是以谋略闻名（如军师）？/ Famous for personal combat prowess or for strategy?" | ~~"此人是文臣还是武将？"~~ |
| "此人是否亲自率军打赢过一场著名战役？/ Personally led and won a famous battle?" | ~~"此人是将军吗？"~~ |
| "此人是否主要在陆地上作战（而非海上）？/ Primarily fought on land rather than sea?" | 通用 |

##### 科学/学术方向

| 推荐问题 | 避免的旧问法 |
|---------|------------|
| "此人的主要成就是关于理解自然世界（物理/化学/生物/天文）的吗？/ Main achievements about understanding the natural world?" | ~~"此人是物理学家吗？"~~ |
| "此人是否发明或发现了某个至今仍在使用的东西/定律？/ Invented or discovered something still used today?" | ~~"此人有什么贡献？"~~ |
| "此人是否主要靠数学工具来工作？/ Primarily worked with mathematical tools?" | ~~"此人是数学家吗？"~~ |
| "此人是否因为与苹果有关的故事而被人熟知？/ Known for a story involving an apple?" | 具体锚定（牛顿为例） |

##### 文学/艺术方向

| 推荐问题 | 避免的旧问法 |
|---------|------------|
| "此人的作品主要是诗歌还是散文/小说？/ Works mainly poetry or prose/fiction?" | ~~"此人是诗人还是小说家？"~~ |
| "此人是否在世时就因为作品而声名远扬？/ Already famous for works during their lifetime?" | ~~"此人知名吗？"~~ |
| "此人的作品是否经常出现在今天的教科书中？/ Works often appear in today's textbooks?" | 通用 |

##### 哲学/宗教方向

| 推荐问题 | 避免的旧问法 |
|---------|------------|
| "此人是否创立了一个新的思想流派（而不仅是追随前人）？/ Founded a new school of thought, not just followed one?" | ~~"此人是哲学家还是宗教人物？"~~ |
| "此人是否因为思想而遭受过迫害或流放？/ Persecuted or exiled for their ideas?" | ~~"此人经历坎坷吗？"~~ |

##### 通用精筛问题（适用于任何方向）

- "此人是否在30岁之前就已经成名？/ Became famous before age 30?"
- "此人是否活过了60岁？/ Lived past 60?"
- "此人是否有过流放、监禁或被迫害的经历？/ Experienced exile, imprisonment, or persecution?"
- "此人是否留下了有明确署名的作品？/ Left works with clear attribution?"
- "此人的名字在今天的日常生活中是否经常被提到（如街道名、品牌名等）？/ Name commonly appears in daily life (street names, brands, etc.)?"
- "此人是否有广为人知的外号或称号？/ Has a well-known nickname or title?"

#### Stage 3: 定位 / Identification (问题13-20)

目标：精确识别具体人物

**策略**：
- 根据已收集的信息，内部生成2-5个最可能的候选
- 用具体的、有区分度的经历来排除候选——不是问"是什么人"，而是问"做过什么事"
- 当信心指数 ≥ 80% 时，可以发起正式猜测

**定位问题示例**（行为导向）：

> "此人是否在战争中以少胜多打赢过一场战役？/ Won a battle against the odds?"
>
> "此人是否到过亚洲/非洲/美洲？/ Ever traveled to Asia/Africa/Americas?"
>
> "此人去世时是否超过70岁？/ Was this person over 70 when they died?"
>
> "此人是否与某个著名的建筑/地标有关？/ Associated with a famous building or landmark?"
>
> "此人的某个具体行为是否成了一个成语/典故？/ Did a specific action of this person become an idiom/story?"
>
> "此人是否有广为流传的与某动物的关联（如骑过某种动物、养过某种动物）？/ Associated with a specific animal in popular stories?"

### Phase 2.5: 投降选项 / Surrender Option

**AI可以选择投降的情况**：
- 20个问题全部问完，仍无法锁定人物
- 3次正式猜测全部用完
- AI经过多轮推理，确实想不到合理的候选

**投降格式**：

```
🏳️ AI投降了 / AI Surrenders!

实在想不出来是谁了，我投降！
I give up — I just can't figure it out.

请揭晓答案吧 / Please reveal the answer:
你心中想的是谁？

[用户回答后]

原来是{人物名}！
{简要介绍此人}

🤔 AI的反思：
这个人物确实{评价}。
AI在{某个维度}上{反思}。
```

**投降原则**：
- 投降是最后的手段，AI应该先尽力推理和猜测
- 真的想不出来时果断投降，不要硬撑浪费时间
- 投降时坦诚幽默，不要找借口

### Phase 3: 正式猜测

当信心指数足够高时，发起正式猜测。

**猜测格式**：

```
🎯 正式猜测 #{N}/3:

我认为此人是中国历史上第一位皇帝——
秦始皇 / Qin Shi Huang (259 BCE - 210 BCE)

我猜对了吗？/ Am I correct?
```

**猜测规则**：
- 每次猜测必须是具体人物（中文名+英文名）
- 最多猜测3次
- 猜错后AI可以继续提问（不额外消耗提问次数）
- 3次都猜错 → 自动进入Phase 2.5投降流程

### Phase 4: 结算

**AI猜对**：
```
🎉 AI猜对了！

正确答案 / Answer: {中文名 / English Name}

📊 本局统计：
├─ 总提问数：{N}个
├─ 正式猜测：{M}次
└─ 评价：{评级}
```

**AI投降**：（由Phase 2.5投降流程处理，此处为补充说明）

投降后的统计展示：
```
📊 本局统计：
├─ 总提问数：{N}个
├─ 正式猜测：{M}次
└─ 评价：{评级}
```

## 推理面板更新规则

每次收到用户回答后更新面板：

### 信心指数计算

```
信心指数 = 基础分 + 加分

基础分：
- 每个已确认维度 +15% (时代/地域/领域/性别)
- 每个已确认子维度 +8% (具体领域、朝代、成就类型等)

加分：
- 已排除的候选类别较多 +5~10%
- 候选人物少于5个 +15%
- 候选人物少于2个 +25%
```

### 面板展示格式

```
📊 推理面板 / Reasoning Panel
├─ 已确认 / Confirmed:
│   • 活跃于19-20世纪 / 19th-20th century
│   • 欧洲人 / European
│   • 科学家 / Scientist
│   • 男性 / Male
├─ 已排除 / Ruled out:
│   • 亚洲 / Asia
│   • 古代 / Ancient era
│   • 政治/军事人物 / Political/Military
├─ 🎯 候选方向 / Top candidates: 物理学家/化学家
├─ 信心指数 / Confidence: ████████░░ 80%
├─ 已提问 / Questions: 8/20
└─ 剩余猜测 / Guesses left: 3
```

## 提问策略原则

### 问题设计核心原则

1. **行为优于标签**：问"做过什么"而非"是什么人"
   - ✅ "亲自上过战场拿武器砍人吗？" → 区分猛将/军师/文官
   - ❌ "是武将吗？" → 说不清诸葛亮算不算
   - ✅ "亲手做过实验/观测吗？" → 区分实践型 vs 理论型
   - ❌ "是科学家吗？" → 太笼统

2. **具体优于抽象**：用可观测的具体行为代替模糊分类
   - ✅ "继承权力还是自己打下来的？"
   - ❌ "是开国君主吗？"（有些开国君主也是继承了一部分权力）
   - ✅ "活过了60岁吗？"
   - ❌ "长寿吗？"（模糊）

3. **场景优于概念**：用情境化的问题增加趣味性
   - ✅ "此人对电灯泡会感到惊讶吗？"
   - ❌ "此人活跃于工业革命之前吗？"（功能相同但无趣）
   - ✅ "此人见过金字塔吗？"
   - ❌ "此人来自北非或中东吗？"（功能相似但枯燥）

4. **二分优先**：每个问题应尽可能将候选空间对半分

5. **多变性**：
   - **同一维度至少准备3-5种不同问法**
   - **每局开场顺序随机**，不要总是 时代→地域→领域→性别
   - **连续两局中，同一维度不得使用相同问法**
   - 根据前几问的回答动态调整后续问题

6. **不问重复**：已确认的信息不再追问

7. **不问模糊**：问题必须有明确的"是/否"答案

8. **动态调整**：根据用户的回答实时调整提问方向

9. **避免诱导**：不在问题中暗示答案

10. **中英双语**：关键问题双语呈现

## 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 用户回答"不确定" | 记录为未知，跳过该维度，从其他角度缩小 |
| 用户回答"不相关" | 认为问题方向有误，回退并换角度提问 |
| 用户给的回答矛盾 | 礼貌追问澄清："你刚才说X，但之前说Y，能确认一下吗？" |
| 用户想的人物太冷门 | 尽力猜测，实在猜不到就投降，鼓励用户分享此人故事 |
| 用户想的是虚构人物 | 提醒规则要求真实历史人物，请重新想一个 |
| 用户说"猜不出来吧"/"投降吧" | AI投降，请用户揭晓答案 |
